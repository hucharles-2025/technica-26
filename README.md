# *Unseen*
## Technica 2026
The lived experiences of those with disabilities or chronic illnesses are often overlooked, and their struggles during the everyday underestimated. *Unseen* puts the player in the shoes of a college student trying to get through a day school. In this decisions-based game, players will struggle against a running clock to balance their health and grades, trying to make it through the day without sacrificing either. 

## How to Run the Project
1. Make sure your computer has [Python](https://www.python.org/downloads/) installed.
     You can check if it is downloaded with `python --version`
3. Once you have Python, use the Command Line to install [Pygame](https://github.com/pygame/pygame)
4. Clone this git repo to your computer and go to the the repos's folder (technica-26), then `cd` to `game_control_server`
5. Run `pip install -r requirements.txt` and `pip install keyboard`
7. Finally, download `pip install pygame_gui` and run `python gui.py` to play the game!
